## Quick Commands

| Command | Description |
|---------|-------------|
| `:pi-start` | Start new session |
| `:pi-continue` | Resume previous (cache-friendly) |
| `:pi-send` | Send prompt |
| `:pi-abort` | Abort operation |
| `:pi-quit` | Close session |

## Debugging

Use `steel interactive`, `:open-debug-window`, `:eval-buffer`. Do NOT use tmux.
